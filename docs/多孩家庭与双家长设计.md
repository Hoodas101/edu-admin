# 多孩家庭 · 双家长共管 · 设计文档

> 目标：一个家长有 2-3 个孩子时，无需切换账号即可查看所有孩子信息、简单报名；两个家长共管一个孩子时不产生冲突。

## 一、核心设计原则

### 1. 账号模型：家长是账号，孩子是数据（不建子账号）
- 一个手机号 = 一个家长账号；孩子是绑定在该家长名下的**数据对象**，不是独立登录账号。
- 家长 `parent_bindings` 可绑定 1-3 个孩子（`is_main` 标记主管理家长）。
- 因此"切换孩子"是**视图切换**（`currentStudentIndex` 全局态），不是"切换账号"——永远不需要退出/重登。

### 2. 多家长共管：单一数据源 + 操作以"孩子"为单位
- 两个家长绑定同一孩子时，`enrollments` / `leave_requests` / `attendances` 都以 `student_id` 为数据主键。
- 家长只是"操作者"，不产生数据分叉：A 报的名，B 端立刻可见（`schedules/my` 按绑定关联查询）。
- 冲突防抖靠**幂等**：重复报名返回"已报名"（按 `schedule_id + student_id` 去重，不重复计数）；重复请假提示"已提交"；满员即止。
- 操作留痕：报名记录写入 `created_by`（哪位家长），供核对与信任建立。

## 二、多孩查看链路（切换器 + 聚合视图）

```
首页顶部「孩子切换条」（chips）
  ├─ [全部] [孩子A] [孩子B] [孩子C]
  │
  ├─ 全部模式：聚合卡片墙（每个孩子一张卡，一屏看全）
  │    ├─ 会员卡：姓名 / 卡种 / 有效期 / 剩余课时
  │    ├─ 今日/24h 活动：该孩子已报名的课
  │    └─ 点卡片 → 聚焦单孩模式
  │
  └─ 单孩模式：与现在一致，聚焦该孩子
       ├─ 会员信息卡（该孩子）
       ├─ 24h 即将开始活动（该孩子已报名）
       └─ 其他页（积分/订单/签到记录/会员中心）跟随当前孩子
```

- 当前选择持久化到 `storage`（`currentStudentIndex`），下次进入保持。
- 数据接口支持 `studentId` 参数：`students/home/data?studentId=`、`points/balance`、`checkin/records`、`membership/my`（已支持）。`orders/my` 目前按家庭维度返回全部订单、仅支持 `status` 过滤，如需按孩子筛单可在前端按 student_id 二次过滤。

## 三、简单报名链路（多孩）

```
活动卡状态展示：已报名孩子列表（"已报：小明、小红"）
  │
  ├─ 单孩模式点报名 → 确认弹窗"为 小明 报名？" → POST enroll(studentId=小明)
  ├─ 全部模式点报名 → 孩子多选弹层（勾选要给谁报，可一次报多个）→ 逐个 POST
  └─ 取消报名 → 指定孩子 → DELETE enroll(studentId=小明)（绝不误删其他孩子）
```

- 后端校验 `studentId ∈ 该家长绑定`，防止报错孩子。
- 已报名由后端按 `schedule_id + student_id` 去重，双家长重复操作安全。

## 四、双家长共管防冲突策略

| 场景 | 策略 | 实现 |
|------|------|------|
| 爸爸已给小明报名 | 妈妈端显示"已报名"，按钮变"取消报名"需确认 | `schedules/my` 按绑定共享 + 活动卡显示已报孩子 |
| 双方同时报名 | 幂等去重，不重复计数 | 后端 `enrollments` 唯一检查 |
| 双方同时请假 | 同一孩子同一课只允许一条 pending | 后端 `leave_requests` 去重（已实现） |
| 满员竞争 | 先到先得，满员即止 | 容量检查在写入前（已实现） |
| 谁操作的 | 报名留痕 `created_by` | `enrollments.created_by`（家长名） |
| 取消误删 | 按孩子精确取消 | DELETE 带 `studentId`（本次修复） |

## 五、业界参考（有赞 / 智慧托管 / 菲特云 / 教培管家）
- 家庭账号 + 亲情号：主账号绑定孩子后，把其他家人手机号加为亲情号，自动同步孩子信息，免重复填写。
- 可折叠"学员切换器"置于顶部，多孩切换成本降为一次点击。
- 多家长绑同一学员（有赞支持最多 6 位），解决"谁送课谁操作"的协同问题。
- 按孩子 ID 做数据隔离与聚合展示。

## 六、本次落地范围
- 后端：报名/取消支持 `studentId`（校验归属）；`enrollments.created_by` 留痕；`schedules/my` 返回每个报名行的孩子信息；`home/data` 支持 `studentId`。
- 小程序：首页孩子切换条（全部/单孩）+ 全部模式聚合卡片墙；活动卡显示已报名孩子；报名/取消按孩子操作。
